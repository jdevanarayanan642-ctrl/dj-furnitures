# DJ Furnitures 🪑

A furniture website showcasing furniture collections, product galleries, and custom furniture request options with a clean, responsive, and user-friendly design.

## ✨ Features

- **Home Page** – An attractive landing page with a hero section.
- **About Page** – Information about the furniture business.
- **Our Works Page** – Showcases available furniture products.
- **Gallery Page** – Displays furniture designs and collections.
- **Custom Request Page** – Allows customers to submit custom furniture requests.
- **Responsive Design** – Adapts to different screen sizes using Bootstrap.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5

   ```bash

   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
